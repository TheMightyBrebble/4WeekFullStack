# 4WeekFullStack
Project based on a full stack system including JavaScript, Node.js and others.
## Description
Simple Database system that will allow a user to add, delete and update their collection of Card Game Decks for better ways to organise their storage.

## Tasks
The user will have database space allocated to them with a log in system that automatically connects to each entry in the Deck table. This will mean that users will only be able to access the decks that are tied to their profile so that there are no issues with accidentally changing another user's data.
The user will be able to add deck names to the system, as well as changing them and deleting them if they are not being used anymore.

## Display
The front end of the system is made using React and will give a display that allows users to customise their data. THe backend will be done using Node.js and JavaScript.
